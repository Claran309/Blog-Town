# Claran's Blog 产品待办

更新时间：2026-11-19

这份文档只记录产品目标、用户体验和验收结果，不记录技术实现方案。

## 当前进度

- 新站正式地址：`https://www.claran-blog.work/`
- 裸域 `claran-blog.work` 已 308 跳转到 `www`。
- 经典版：`https://classic.claran-blog.work/`
- 新站已从 GitHub 自动部署，生产分支为 `personal/claran-latest`。
- 新站评论沿用 Twikoo，历史评论已验证可显示。
- About 页面、中心风车地标、留言板、短日记与友邻聚落已完成。

## 上线原则

- 新站先完整验收，再承接主域名。
- 旧站在经典版地址继续可用，旧文章链接不能中断。
- 所有未完成的独立页面必须有明确去向，不能出现死链。
- 不为了迁移而迁移：旧主题中已经关闭或与小镇体验冲突的功能，可以留在经典版。

## P1：新站独立页面

**状态：已完成（2026-11-19）**

**目标**

**建议内容**

**验收**

- 从首页可以自然进入 About。
- 页面内容与当前侧边栏简介不冲突。
- 移动端阅读完整。

### 6. 项目页面

## P2：友邻与小镇体验

### 8. 友邻小镇聚落

**状态：已完成（2026-11-19）**

- 主城区东南外侧新增「友邻聚落」：9 间小屋沿弧线排开，一条土路从主城区接入。
- 选中友邻后镜头缓动平移过去，小屋高亮、上方浮出名片，列表保持展开。
- 小屋不计入文章建筑、系列楼层与文章数量，只参与避让。
- 移动端使用同一套选中逻辑。

**产品目标**

- 把友链从普通列表升级为小镇的一部分。
- 让“去朋友家串门”成为浏览友链的自然动作。

**体验设想**

- 友邻住在远离主城区的一组特殊小屋里。
- 打开友邻列表后，列表保持展开。
- 选中一位友邻时，小镇视野移动到对应小屋并高亮。
- 用户可以继续在列表中选择其他友邻，也可以从卡片进入对方网站。
- 友邻小屋不计入文章建筑、系列楼层和文章数量。

**验收**

- 9 位友邻都能在列表和小镇中找到对应关系。
- 选中友邻后，列表状态不会消失。
- 移动端同样可以完成“选择友邻 → 看见小屋 → 访问网站”。
- 主城区文章建筑的位置和阅读入口不受影响。

### 9. 图片体验优化

**产品目标**

- 文章图片打开更快，长文章滚动更顺畅。
- 不牺牲封面和正文图片的清晰度。

**验收**

- 弱网下正文不会长时间被大图阻塞。
- 封面、正文大图、缩略图在不同屏幕上显示合理。
- 图片地址改变后旧文章仍能正常显示。

### 10. 站点累计数据

**状态：已完成（2026-11-19）**

- About 统计卡展示：文章数、累计字数、运行天数、访问人数；主页场景下方也有同源小卡片。
- 字数统计口径与经典站完全一致（剔除代码块与行内代码后按 CJK 字符 + 非 CJK 词计数），当前 112,450 字。
- 运行天数继承经典站建站日 2025-10-12，不在新域名上重新起算。
- 文章数/字数/天数在构建期计算，永远准确；访问人数来自 `/api/views` 的全站合计。
- 计数不可用时显示「—」，不会显示假的 0。
- 历史基线按经典站流量估算写入（26,000 浏览量 / 7,200 访问人数）；旧站未配置 Umami，无实测数据可迁。

**产品目标**

- 让访客一眼看到博客的长期积累，而不是只看到当前页面。

**建议展示**

- 累计访问人数。
- 累计文章数。
- 累计字数。
- 可选：博客运行天数、累计评论数。

**验收**

- 数据含义明确，访问人数和页面浏览量不会混用。
- 数据在首页或侧边栏稳定展示，不影响小镇加载。
- 数据异常时有兜底状态，不显示明显错误的数字。

### 11. 文章阅读量

**状态：已完成（2026-11-19）**

- 文章页 meta 显示「N 次阅读」。
- 与站点累计数据共用 `/api/views`（Vercel Function + Upstash Redis）。
- 同 IP + 路径 30 分钟去重；快速切换文章时丢弃过期响应。
- 仅生产域名上报，本地与预览不上报。

**产品目标**

- 让文章页可以看到单篇阅读情况，并与站点累计数据区分。

**验收**

- 明确展示的是阅读人数还是阅读次数。
- 历史阅读量是否继承有明确结论。
- 文章快速切换时计数不会重复或错位。
